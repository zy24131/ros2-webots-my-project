# my_project 架构说明

```text
┌─────────────────────────────────────────┐
│  L3 fsm（Trigger + Action 客户端） │
└──────────────────┬──────────────────────┘
                   │ /my_robot/mode
┌──────────────────▼──────────────────────┐
│  L2 steering_control → steering_command│
│  L2 actuator_control  → joint_commands   │
│  L2 wheel_speed_control → wheel_speeds    │
└──────────────────┬──────────────────────┘
                   │ ROS2 话题
┌──────────────────▼──────────────────────┐
│  L1 hardware_bridge（Webots 仿真实现）    │
│  真机：替换为 valve_driver / PLC 节点      │
└──────────────────┬──────────────────────┘
                   │ Webots API / 现场总线
┌──────────────────▼──────────────────────┐
│  webots/ 或 液压阀控硬件                   │
└─────────────────────────────────────────┘
```

## 与参考项目 (work/study) 对照

| 参考模式 | 本工程实现 |
|----------|------------|
| chassis 合并下发 | `actuator_control` 唯一发 joint_commands |
| FSM + Manager | `fsm` Trigger 表（轻量） |
| 算法独立 | `robot_kinematics` 纯 C++ |
| launcher 分层 | `control_bringup.launch.xml` + yaml 参数 |
| 就绪链 | `actuator_control` 收到 `joint_states` 后内部开始发令 |

详见 [steering_flow.md](steering_flow.md)。
