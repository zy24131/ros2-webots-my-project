# my_project 架构说明

```text
┌─────────────────────────────────────────┐
│  steering_controller  →  steering_command│
│  actuator_executor    →  joint_commands   │
│  mobility_controller  →  wheel_speeds     │
└──────────────────┬──────────────────────┘
                   │ ROS2 话题
┌──────────────────▼──────────────────────┐
│  hardware_bridge（Webots；真机换 CAN 驱动）│
└──────────────────┬──────────────────────┘
                   │
┌──────────────────▼──────────────────────┐
│  webots/ 或 下位机 ECU                    │
└─────────────────────────────────────────┘
```

当前仅 **窄轮距转向 + 固定轮速**，无 FSM / 宽轮距 / 自转 / Action。

详见 [steering_flow.md](steering_flow.md)、[ros2_communication.md](ros2_communication.md)。
