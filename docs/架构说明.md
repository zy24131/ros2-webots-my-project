# my_project 架构说明

```text
┌─────────────────────────────────────────┐
│  L3 robot_fsm（Trigger + Action 客户端） │
└──────────────────┬──────────────────────┘
                   │ /my_robot/mode
┌──────────────────▼──────────────────────┐
│  L2 steering_controller → steering_command│
│  L2 actuator_executor  → joint_commands   │
│  L2 mobility_controller → wheel_speeds    │
└──────────────────┬──────────────────────┘
                   │ ROS2 话题
┌──────────────────▼──────────────────────┐
│  L1 hardware_bridge（Webots 仿真实现）    │
│  真机：替换为 valve_driver / PLC 节点      │
└──────────────────┬──────────────────────┘
                   │ Webots API / 现场总线
┌──────────────────▼──────────────────────┐
│  webots/ 或 液压阀控硬件                   │
└─────────────────────────────────────────┘
```

## 与参考项目 (work/study) 对照

| 参考模式 | 本工程实现 |
|----------|------------|
| chassis 合并下发 | `actuator_executor` 唯一发 joint_commands |
| FSM + Manager | `robot_fsm` Trigger 表（轻量） |
| 算法独立 | `my_robot_maps` 纯 C++ |
| launcher 分层 | `control_bringup.launch.xml` + yaml 参数 |
| 就绪链 | `/my_robot/system_ready` |

详见 [steering_flow.md](steering_flow.md)。
