# my_project 架构说明

布局参考 `ros_bridge/`：Webots 与 ROS2 分目录，互不混放。

```text
┌─────────────────────────────────────────┐
│  wheel_bringup（纯 ROS2）               │
│  wheel_publisher → /my_robot/wheel_speed│
└──────────────────┬──────────────────────┘
                   │ ROS2 话题
┌──────────────────▼──────────────────────┐
│  webots_ros2_bridge（仿真桥接）       │
│  ros2_bridge.cpp → Webots Motor API   │
│  安装到 webots/controllers/ros2_bridge│
└──────────────────┬──────────────────────┘
                   │ Webots API
┌──────────────────▼──────────────────────┐
│  webots/（仿真模型，不含 ROS 源码）     │
│  worlds / meshes / protos / controllers │
└─────────────────────────────────────────┘
```

## 与 ros_bridge 对照

| ros_bridge | my_project |
|------------|------------|
| `my_robot/` | `webots/` |
| `ros2_ws/` | `ros2_ws/` |
| `run_webots.sh` | `run_webots.sh` |
| 双轮 cmd_vel | 四轮 wheel_speed |

## 修改指南

| 目标 | 文件 |
|------|------|
| 改轮速逻辑 | `ros2_ws/src/mobility_bringup/src/mobility_node.cpp` |
| 转向映射算法 | `ros2_ws/src/my_robot_maps/`（窄/宽 al.cpp 链） |
| 改桥接/腿锁定 | `ros2_ws/src/webots_ros2_bridge/src/ros2_bridge.cpp` |
| 改模型/关节 | `webots/worlds/my_project.wbt`（不动 ros2_ws） |
| 本地测试无 ROS | `webots/controllers/void/void.c` |
